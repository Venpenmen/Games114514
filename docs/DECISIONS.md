# 实现决定
- 夜晚默认 60 秒，白天默认 120 秒。
- 指认及重投的公开结果展示 3 秒。结果阶段禁止发言，结束后按规则重投、入夜或公开身份。
- 恢复阶段时，以已经到期的原截止时刻作为下一阶段的时间锚点，逐阶段追赶至当前服务器时间。


## GAME 02

- 投票结果展示 3 秒，非冠军单局结果展示 8 秒并自动续局。上一局结果完整保留，打开结果窗时固定已打开的记录。冠军结果持续至新比赛或房间关闭。
- 大厅选择接入可选插件接口；每场比赛单独选形象。整场比赛使用平台已生成的 matchId，单局用比赛 ID 加局序号识别。沿用现有 SQLite 结构。
- 使用 CSS 3D 六面骰、生成的酒馆与六幅肖像、本地合成的碰撞音；减弱动态模式下关闭骰子及气氛动画。
