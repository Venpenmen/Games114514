# P18 平台级机制反馈约定与双游戏视觉反馈实施记录

日期：2026-11-16。分支：`feature/dice-werewolf`。实施范围：**前端结算反馈与开发规范**；不修改服务端规则、联机协议、数据库或 FRP。当前《忍者之夜》仅有规则资料，不在本次美术改造范围内。

## 规范

- 平台统一规范：`docs/MECHANICS_VISUAL_FEEDBACK.md`，入口：`AGENTS.md`。
- 统一四层反馈：选择/提交 L1、正在执行 L2、公开结果 L3、胜负/冠军 L4。
- 每款游戏自行选择主题资源和色彩，不要求美术同质化；突出公开结果不得暴露秘密行动。
- 快速连续事件的完整队列回放需要未来插件侧提供公开事件序号；本轮仅使用现有公开快照的最近结果，不改协议。

## 《诡吹灯》

- 原九宫格选中样式保留；夜间公开结算后，对最终改变的蜡烛做短暂轮廓高亮和点亮/摧毁提示。
- 使用 `state.last` 中已公开的唯一蜡烛与结果，不显示任何人的秘密选烛动作。
- 最近夜晚结算和公开指认结果用可读文字及不同底色说明。公开票型无多数时也能直接看到提示。
- 游戏规则、原有胜负弹窗、聊天与响应式区域不变。

## 《骰子狼人杀》

- 当前逐点报数高亮保留；`state.last` 新增与对应骰子关联的正/负数值浮层和短暂聚焦。
- 依据公开 `state.executions` 突出处决目标，包含多点数同时处决；区分「待处决」与「已处决」。
- 投票结果增加多数票/无多数票提示，最近处决记录增加直接可读的结算说明。
- 保持西部酒馆配色和骰子素材；普通局、加赛、冠军和历史弹窗沿用现有机制。

## 安全与可用性

- 动画 CSS 使用 transform/opacity，不触发服务器行动、不阻止阶段推进。
- `prefers-reduced-motion: reduce` 禁用动态缩放/浮层动画，仍有文字和边框提示。
- 断线重新载入不凭空播放久远事件；已有最新公开结果仍可查阅。
- 不改变双方秘密身份、骰子身份、投票保密和房间权限。
