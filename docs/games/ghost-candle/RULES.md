# GAME 01：《诡吹灯》v1.0 冻结规则

## 角色与胜利
- 固定3名真人：2名 HUMAN（人类）1名 GHOST（诡异），每局服务端随机分配，本人可见，其他人不可见。
- 9根编号1至9的蜡烛，初始 INTACT。每晚恰好将1根 INTACT 变成 LIT 或 DESTROYED；已处理不可再次选择。
- LIT 达到5根或正确指认GHOST：人类阵营胜；DESTROYED达到5根或错误指认HUMAN：诡异阵营胜。每夜优先检查蜡烛胜负，胜则直接结束。
- 最多9夜必有胜负，无平局。

## 夜晚
- 房主选择夜晚时长 30/60/120/180秒。两名人类各选择完整蜡烛，动作只能LIGHT；诡异选择完整蜡烛，并指定 LIGHT 或 DESTROY。
- 玩家秘密确认后不能修改；三人提交立即结算；超时未提交，人类随机完整蜡烛LIGHT，诡异随机完整蜡烛DESTROY。
- 只公布夜晚最终变化的蜡烛及状态，不公布个人行动或诡异动作。
- 从上至下匹配，命中即停止：
  1. 诡异 DESTROY 目标与至少一名人类目标相同→该目标 DESTROYED。
  2. 两名人类同选一根，且未触发1→该根 LIT。
  3. 诡异 LIGHT 目标与至少一名人类目标相同，且未触发1、2→该根 LIT。
  4. 其余情况，从当晚全部完整蜡烛中随机抽取一根 DESTROYED。
- 诡异单独点亮不生效；单独摧毁未命中人类时进入随机摧毁；每晚仅变化一根。

## 天数、白天聊天与寻找
- 首先是第1夜；第1夜结束后是第2天、第2夜后第3天、第3夜后第4天。
- 每晚未分胜负后都进入 DAY_DISCUSSION。房主开局前选白天时长60/120/180/300秒，默认120。三人均点击结束讨论也可提前推进；已确认仍可聊天。
- 第2、3天讨论完直接下一夜；第4天及以后才开放 DAY_DECISION。
- 白天 DAY_DISCUSSION、DAY_DECISION、ACCUSATION、REVOTE 均允许文字公聊，可回看本局此前聊天；夜晚/结算/身份阶段禁发言。当前版本不做实时语音。
- DAY_DECISION：30秒或全员提交即结算，三人分别选“寻找诡异”或“继续入夜”，至少2票同意才进入指认，否则下一夜；未提交弃权。
- ACCUSATION：30秒或全员提交即结算，每人一票（包括诡异），只能指认另外两名玩家，不能选自己；提交不可修改；超时弃票。投票时保密，只显示提交状态。
- 有某人获得至少2票则有效指认；指认GHOST人类胜、指认HUMAN诡异胜。没有人达到2票则REVOTE一次（30秒）；第二次仍无人达到2票则寻找失败，下一夜。
- 每轮结束均公开三人各自票投向谁或弃票，并留短暂结果展示时间；同一天不再重复讨论和发起寻找。

## 房间、玩家、断线
- 公共平台负责六位房间码、分享链接、三人加入、游客身份、头像昵称、准备、踢人（仅未开始）、解散、房主设置及再来一局。房主掉线保留房主资格。
- 首次游客设置昵称和预置头像，后续自动恢复，可在个人资料页修改；游客身份凭证安全存储，换设备是新游客（未来可扩展绑定）。
- 断线不暂停服务端截止时间；回连恢复原席位与本人私有状态；超时按阶段自动动作或弃票。
- 重赛沿用房间玩家，重置蜡烛/日夜/投票并重新随机身份；不长期保留战绩；对局结束后清理临时数据。
- 服务器必须处理重放、并发、重启恢复、私密状态泄露、恶意越权和迟到操作。
