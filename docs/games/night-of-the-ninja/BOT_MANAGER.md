# 《忍者之夜》统一机器人管理器

双击项目根目录 **ninja-bot-manager.cmd**。窗口常驻，不会因输错房间号、难度、人数或加入失败自行关闭。

1. 选择 1「启动或切换房间」，选择 3216（默认 P20）或 3213 原试玩版。
2. 输入当前服务器上的六位《忍者之夜》房间码（如 048325），保持前导 0。
3. 输入机器人数量 1～10，且需小于房间设置的正式人数、并有足够空席位。
4. 难度输入 `1`（简单，随机）、`2`（普通，规则启发）、`3`（困难，强化启发），也可以输入如 `1,3,2` 分别设置 3 位机器人。困难是更积极的启发式决策，不是完整博弈搜索。
5. 确认 Y 后，旧机器人组会先断开，随后新组加入、选择肖像并准备。
6. 选菜单 2 停止此管理器启动的机器人；选 3 查看状态；选 0 退出并清理机器人。

只管理对应项目的机器人，不重启 3213/3216、正式 3199、FRP，也不修改数据库。
机器人如果在**已经开始的比赛**中断开，其席位仍由游戏的断线规则决定；等待房间内机器人会主动离开并释放席位。
旧 `ninja-bots.cmd` 已弃用，旧 `scripts/ninja-bots-cli.ts` 仅保留为遗留参考代码，不再作为入口。

**测试提醒**：需要先在所选端口创建《忍者之夜》等待房间；管理器不自动创建房间。新管理器只能停止自己启动的机器人；迁移时已通过旧版管理命令停止两套原有机器人。
