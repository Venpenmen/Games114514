## 1. 游戏目标与身份

**[原版]** 4～11 名玩家。身份为鹤派 Crane、莲派 Lotus，以及奇数人数时额外加入的浪人 Ronin。每个流派使用等级 1～5（1 最高）的身份卡，按人数加入前几个等级；每轮重新分发。游戏中身份可因变形者改变。

| 人数 | 鹤派 | 莲派 | 浪人 |
|---|---:|---:|---:|
| 4 | 2 | 2 | 0 |
| 5 | 2 | 2 | 1 |
| 6 | 3 | 3 | 0 |
| 7 | 3 | 3 | 1 |
| 8 | 4 | 4 | 0 |
| 9 | 4 | 4 | 1 |
| 10 | 5 | 5 | 0 |
| 11 | 5 | 5 | 1 |

**[原版]** 每轮存活成员中，等级更高（数字更小）的一派获胜；最高等级相同时继续比较双方下一位存活者。完全打平则无获胜流派，所有存活者各获得一枚荣誉标记。获胜流派的**所有成员（含死者）**各抽一枚荣誉；存活浪人亦抽一枚。荣誉是个人财产，比赛在完整轮次、揭示及全部荣誉结算后检查：有人总分达到 10 分则比较达标者的最高分，并列最高者共同获胜。**不加赛**。

**[原版]** 荣誉面朝下持有，每枚价值 2、3 或 4 分；公开每人持有的枚数，隐藏他人标记分值与累计分数。自己可以查看自己的标记和总分。荣誉标记上的分值不因换主人而改变。

## 2. 一轮完整流程

1. **分发流派卡**：各人秘密获得一张身份卡，能在尚未被交换限制时查看自己身份。
2. **轮抽第一步**：每人获得 3 张忍者牌，秘密留 1 张，其余 2 张向左传给下一人。
3. **轮抽第二步**：从收到的 2 张中秘密留 1 张，其余 1 张加入弃牌区；未发出的忍者牌暂放旁边。
4. **五阶段夜晚**：密探 Spy → 隐士 Mystic → 骗徒 Trickster → 盲眼刺客 Blind Assassin → 上忍 Shinobi。
5. **流派揭示**：活着的玩家公开当前真实流派；可用的首脑特殊牌在此阶段处理。
6. **流派及浪人奖励**：先确认获奖集合，必要时补荣誉池，再随机发放。
7. **比赛终局检查**：全部奖励发放后，判断是否出现达到 10 分者；否则进入轮间结算和准备，接着下一轮。

**[原版]** 夜晚各阶段可以讨论、欺骗、公开声称情报；死亡玩家仍可说话，但不继续正常出牌。死亡不自动公开流派。

**[数字版]** 轮抽和夜晚公聊开放。所有当前有操作资格的玩家提交后立即推进；否则倒计时到期按对应超时规则处理。每阶段先**秘密提交是否出牌**，到提交屏障后**统一亮牌**，再按该阶段牌面编号从小到大逐张结算。反应必须在当前攻击结束前处理，之后才能执行下一张牌。

## 3. 忍者牌及技能

**[原版／交叉核验]** 忍者牌总计 **33 张**：密探、隐士、盲眼刺客、上忍各 **6 张（每种编号 1～6）**，六张技能各异的骗徒（编号 1～6）及三张特殊牌（镜僧、殉道者、首脑各 1 张）。即 **6×4 + 6 + 3 = 33**。类别分布由实体开箱资料直接列明，与官方规则书的总数、五阶段及骗徒编号一致；见 SOURCE_AUDIT.md。

| 阶段/类型 | 卡牌 | 效果概要 |
|---|---|---|
| 1 | 密探 Spy | 私下查看其他一名玩家的当前流派卡 |
| 2 | 隐士 Mystic | 私下查看其他一名玩家的流派卡与其一张忍者牌；目标若有两张，由查看者随机选其中一张 |
| 3 / 骗徒 1 | 变形者 Shapeshifter | 先查看两名玩家身份，决定是否交换，再决定是否揭示结果。房主开启「变形者强制公开结果」或任意目标身份牌已完全暴露时，必须公开是否交换。隐藏时两名目标收到同样的可能变化提示，本轮复盘公开实际结果 |
| 3 / 骗徒 2 | 掘墓人 Grave Digger | 查看两张弃置忍者牌，取其中一张；可立即使用或留待之后的合法使用时机 |
| 3 / 骗徒 3 | 捣乱者 Troublemaker | 查看一名其他玩家流派，可将其公开 |
| 3 / 骗徒 4 | 灵媒商人 Spirit Merchant | 查看另一人的一枚荣誉标记或其流派，可与其交换各一枚荣誉；不必交换已查看那枚 |
| 3 / 骗徒 5 | 窃贼 Thief | 公开自身流派，从荣誉**枚数**比自己多的人处取走一枚荣誉 |
| 3 / 骗徒 6 | 审判者 Judge | 公开自身流派，指定并杀死一名玩家；镜僧/殉道者不能响应 |
| 4 | 盲眼刺客 Blind Assassin | 指定一名玩家并刺杀 |
| 5 | 上忍 Shinobi | 指定一名玩家、查看其流派，再决定是否杀死 |
| 反应 | 镜僧 Mirror Monk | 遭盲眼刺客或上忍刺杀时，反杀攻击者，自己免于该次杀害 |
| 反应 | 殉道者 Martyr | 遭盲眼刺客或上忍刺杀时，获得一枚荣誉，自己仍承受攻击 |
| 揭示 | 首脑 Mastermind | 持有人活到揭示时，使自己流派胜利；浪人持有则两大流派均不获流派奖励，存活浪人仍得奖励 |

### 3.1 原版特别解释

- 密探/隐士看到的内容可以自行告诉其他人，也可以撒谎，系统不自动公开秘密结果。
- 变形后玩家不能自行再次查看变更后的新流派，但可通过后续合法技能得知。
- 掘墓人获得其他阶段的牌时，原版允许立即打出，或保留到尚未到来的合法阶段。
- 灵媒商人可以查看一枚荣誉，却交换对方另一枚未查看的荣誉。
- 窃贼比较的是荣誉**枚数**而不是累计分数；夜晚提前达到 10 分不立刻结束比赛。
- 原版刺杀反应只针对盲眼刺客/上忍；审判者攻击不可用镜僧或殉道者响应。

### 3.2 数字版技能约束

- 强制目标未提交且超时：系统从当前合法目标中随机代选。
- 可选效果超时：默认**不发动**；不可强迫变形者交换、上忍杀人或灵媒商人交换荣誉。
- 已公开技能原目标失效：若技能允许重选则重新选合法目标，超时随机选择；无合法目标时效果失效。
- 已死亡者不能继续正常发动未执行技能。
- 同次刺杀中同时持有镜僧和殉道者的目标，最多选择使用其中一张反应牌。
- 仅攻击目标收到秘密反应提示，超时不反应；完成反应后才结算后续牌。
- 掘墓人先看到两张弃牌并选一张，再选立即使用或保留；超时默认保留。错过合法时机后本轮不能发动；所有牌本轮结束收回，不跨轮保留。
- 使用首脑的浪人阻止两大流派取得流派奖励，但自己如存活仍有奖励；由揭示阶段自动结算。

## 4. 技能、反应与死亡结算矩阵

### 4.1 执行顺序

1. 按夜晚阶段逐个进入，相关存活玩家秘密提交打牌意愿。
2. 统一亮牌，按牌面编号排序；同阶段无人亮牌则继续下一个阶段。
3. 逐张确认操作者有资格、牌有效，必要时选择合法目标。
4. 对查看/交换/公开/夺取/杀害逐项处理；属于私人信息的仅发给有权限玩家。
5. 对可响应的刺杀先打开反应窗口，结算镜僧或殉道者，再完成当前攻击结果。
6. 该张牌执行完毕后才执行下一张；所有本阶段牌结束后进入下一阶段。

| 攻击 | 无反应 | 镜僧 | 殉道者 |
|---|---|---|---|
| 盲眼刺客 | 目标死亡 | 攻击者死亡、目标存活 | 目标死亡、目标先获得一枚荣誉 |
| 上忍确认刺杀 | 目标死亡 | 攻击者死亡、目标存活 | 目标死亡、目标先获得一枚荣誉 |
| 上忍放弃刺杀 | 无伤害 | 不触发 | 不触发 |
| 审判者 | 目标死亡 | 不可发动 | 不可发动 |

**[数字版]** 对同一次攻击，最多有一张反应牌生效；超时视为无反应。一次行动只结算一次，重复提交和断线重发不得重复杀害或发荣誉。

### 4.2 同阶段、死亡和目标失效

| 状态 | 处理 |
|---|---|
| 同阶段多牌 | 先统一亮牌，再严格按卡牌编号逐张结算 |
| 反应中 | 暂停后续牌结算，先完成该次攻击 |
| 亮牌玩家在执行前已死亡 | 不继续执行其未结算的普通技能 |
| 技能目标在执行前已死亡/不合法 | 按技能合法目标范围检查；允许时重选，超时合法随机；无目标则失效 |
| 可选交换或可选杀害未确认 | 不发动可选效果 |
| 攻击不触发反应条件 | 不展示反应操作 |
| 玩家本轮未使用的牌 | 回收、下一轮重新洗牌并轮抽 |

**[已核实]** 同一普通阶段内的编号均为 1～6 且每号各一张，不存在同阶段重号；特殊牌在独立反应／揭示窗口使用。按原版从小到大执行即可，不需要人为发明同号先后。

## 5. 荣誉与轮末结算

1. 完成所有五阶段和可触发的合法反应。
2. 对存活的首脑持有者执行揭示效果；不存在适用首脑时按最高存活等级比较。
3. 确定获奖玩家：获胜流派所有成员（即使死亡）、存活浪人；完全平局则按原版向所有存活者发奖。
4. **[数字版]** 若所有人死亡，既无获胜流派亦无存活奖励；已经通过技能获得的荣誉保留。
5. **[数字版]** 奖励前先检查剩余荣誉标记；不足覆盖全部获奖者，先按原组成补池，再为每位获奖者分别随机抽取一枚，记录补池事件。
6. 奖励发完后检查冠军；有达标者则结束整场，未达标则进入 30 秒轮间准备；全员提前确认可立即进入下一轮。

**[原版／已核实]** 原版 SETUP 正文指定洗混 35 枚荣誉标记，每枚价值 2、3 或 4 分。不同版次盒内清单有“30 + 5 extra”和“35 + 5 extra”差异；尚无官方明确公布的三种分值构成。玩家清点 40 枚配件为 2 分×16、3 分×16、4 分×8，但未辨认 5 枚备用。**[数字版推定配置／经用户授权] 正式 35 枚池采用 2 分×14、3 分×14、4 分×7（概率 40%／40%／20%，新池单抽期望 2.8 分，合计 98 分）**：严格保留该实物清点中的 2:2:1 比例，不伪称官方确认。抽取采用有限奖池无放回；不足发放时按已冻结规则补入同样 14／14／7 的新池并公开记录。该分布为数字版自主设定。

## 7. 房间、倒计时、断线及异常矩阵

**[数字版]** 房主设置并锁定 4～11 的人数，必须满员且所有正式玩家准备才开局。开局后禁止新增正式席位。允许仅看公开信息的旁观者。正式玩家退出只视为离线，保留席位、身份和荣誉；玩家本人重连后恢复控制。

**[数字版默认倒计时]** 轮抽 45 秒；阶段出牌提交/统一亮牌 30 秒；技能目标 30 秒；刺杀反应 15 秒；轮间结算与准备 30 秒。房主可以调整前四类时间，调整范围待定。计时由服务端主持，不以客户端本地计时为准。

| 场景 | 处理 |
|---|---|
| 所有相关玩家提前完成操作 | 立即进入下一步，非参与者不阻塞 |
| 轮抽超时/掉线 | 从合法手牌中随机代选 |
| 本阶段是否亮牌未提交 | 视为不打出 |
| 必须选择目标超时 | 从合法目标中随机代选 |
| 可选效果超时 | 不发动 |
| 被刺杀者反应超时 | 不反应 |
| 掘墓人已取得牌但未选择使用方式 | 默认保留，不跨轮 |
| 一名玩家掉线或主动退出 | 保留正式席位及整场角色，超时托管，重连恢复 |
| 房主主动退出 | 向另一位在线正式玩家移交管理权，不变更游戏身份 |
| 房主掉线超时 | 自动转移房主管理权；精确阈值待定 |
| 没有在线正式玩家可接管房主 | 暂缓转移，待有效玩家重连处理 |
| 所有正式玩家离线 | 暂停计时与托管推进，保留当前状态 |
| 仅旁观者在线 | 仍按全部正式玩家离线处理 |
| 任意有效正式玩家重连 | 恢复原剩余计时和正常流程 |
| 轮间有人未确认 | 30 秒到期自动准备；全员提前确认立即推进 |
| 玩家开局后企图替换掉线席位 | 拒绝作为新的正式玩家加入 |
| 重复行动、并发推进 | 同一动作和结算不得重复生效 |

管理权与流派角色独立：房主变更不改变流派、等级、忍者牌、荣誉与已提交操作。轮间准备与所有正式玩家离线暂停规则同时生效。

## 9. 原版与数字版冲突审查及未完成核验

**已核实的原版基线**：4～11 人；身份人数；33 张忍者牌；5 阶段；同阶段编号升序；轮抽 3→1→左传 2→1；死人可继续说话；镜僧、殉道者、首脑特殊用途；完全平局与存活浪人奖励；每轮末跨 10 分终局。FAQ 支持变形后不自由查看、隐士随机看一张牌、掘墓人可越阶段使用、灵媒商人可换未看过的荣誉、窃贼夜晚达标延迟终局。

**数字版有意改变的交互**：统一秘密提交/同步亮牌、时限与托管、身份变化的模糊提示、历史情报持久化、一次攻击最多选择一反应、已失效目标重选、全员离线暂停、可旁观等。这些约定需在开发/帮助文案中明确标注为线上化处理。

**尚未核实的关键项：**

- D01：**已核实**。四类普通技能牌各 6 张，编号 1～6；六张骗徒编号 1～6；镜僧、殉道者、首脑各一张；总计 33 张，同阶段无重号。实体开箱资料 + 官方规则相互校验。
- D02：**数字版配置已确定为 35 枚＝2 分 14、3 分 14、4 分 7**（按实物 40 枚 16／16／8 比例等比例缩减）；原版实物的正式 35 枚真实分布与不同印刷版额外标记口径仍未有官方确认，但不再阻塞数字版规则配置。
- D03：房主调节四种倒计时的最小/最大值及步长；房主掉线管理权转移的秒数。
- D04：掘墓人查看的**初始弃牌至少 4 张**（4 人局），且牌库只有一张掘墓人；因此正常轮抽无需处理不足两张。若取得反应牌或首脑牌，仍须明确其合法触发时机（不能在没有攻击时发动反应）。
- D05：**已排除**。完整卡组只有一张首脑牌，不存在两个首脑同时触发的冲突。

- D08：同轮有并发反应、玩家死亡、重连提交时，怎样保证服务端单次结算与不泄露未公开选择。
