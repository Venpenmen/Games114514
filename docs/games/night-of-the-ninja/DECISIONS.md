# Game 03 数字版实现决定

- 任务书补齐旧冻结稿中的档位、120 秒主持权、掘墓人特殊窗口及荣誉补池。奖池比例 14／14／7 属数字版配置，原版实物分布仍未证实。
- 各技能目标默认为当前存活对象。需要另一名目标时排除自己；变形者可选包含自己在内的两名不同存活玩家。没有合法目标时跳过。
- 房间策略能力按插件选择。租约按已认证用户在线状态与房间主动离开标记判定，未连接正式席位时保持暂停。服务器运行检查点约每秒持久化，正常关闭另保存最后时点，异常中断的可恢复误差上限取决于检查点间隔。暂停不触发自动托管，旁观不恢复计时。
- 旁观加入是独立 Socket.IO 订阅，只发公开快照。公开房间码只用于选择公开观战目标。私人情报有单独序列，不在公开事件留下序号缺口。
- 服务端为已裁决事件发布顺序和演出时段。客户端跳过过期演出，刷新或重连从最新序列开始。到达选择或反应阶段立即可操作。
- 原概念图未在项目内发现。内置 imagegen 先生成月下城堡，再用同一电影质感及冷藏青暖金色标制作牌面、肖像、家纹图集。保留真实 WebP 与程序化 CSS 分类，禁止原版牌面、生成文字与标记。背景音乐和技能音源保持后续项目范围。
