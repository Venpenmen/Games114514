# 平台架构
公共服务按 gameId 和插件版本解析规则。插件拥有配置、人数、命令、计时、聊天策略、终局及公开和个人投影。Web 根据游戏目录加载专属界面。
SQLite 事务保存房间、对局阶段和请求回执。使用服务端绝对截止时间恢复，按阶段标识拒绝迟到命令。提交事务后才向成员发送与身份绑定的投影。
每局结束清空准备状态并保留原成员。房主在成员重新准备后开启新局。


## 《骰子狼人杀》的比赛生命周期

公共 matchId 覆盖整场积分赛。插件用 matchId 与局序号唯一定位单局，并保存跨局单调递增的阶段号。计分、整批处决和阶段推进作为同一房间快照写入 SQLite；旧请求继续由公共回执与阶段校验处理。公共投影包含积分和已公开票型，私有投影仅含本人的身份。从上一局保留的公开结算中读取历史身份。

GamePlugin 可选择提供大厅选择校验与准备条件，平台按已认证成员保存选择并在开局传给插件。Web 同时支持可选的大厅组件注册。既有插件及旧房间数据沿用原流程。
